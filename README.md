# 🎣 PhishiMi 


Ferramenta educacional de simulação de phishing para CTFs e treinamentos de segurança.

## 📋 Funcionalidades

- ✅ 5 templates prontos (Facebook, Instagram, Google, Netflix, TikTok)
- ✅ Dashboard em tempo real com auto-atualização
- ✅ QR Code para acesso mobile
- ✅ Banco de dados SQLite integrado
- ✅ Interface web responsiva
- ✅ Captura automática de credenciais
- ✅ Exportação de dados em JSON/CSV
